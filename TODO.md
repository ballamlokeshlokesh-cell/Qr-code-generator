# QR Forge Project Roadmap & Delivered Features

- [x] **URL & Text QR Generation** — Enter and validate URLs or text, live preview, and download as PNG/SVG.
- [x] **Image-to-QR Generation (Fixed)** — Seamless client-side cloud hosting that works reliably on static hosting (GitHub Pages), localhost, and Docker without failing.
- [x] **Image-to-Link Generator (3rd Option)** — Upload any image to instantly generate shareable links, direct image URLs, Markdown, HTML embed codes, and BBCode with one-click copy buttons and live preview.
- [x] **Real-time Upload Progress Bar** — Visual animated progress bar with percentage indicator during upload.
- [x] **Storage Provider Settings** — Instant default cloud engine + optional personal ImgBB API key configuration.
- [x] **QR Styling Controls** — Soft rounded, square, dot matrix, classy, and curated studio palettes.
- [x] **Download & Clipboard Controls** — High-res PNG, vector SVG, clipboard image copy, and link copy.
- [x] **Responsive Mobile Layout** — Floating preview jump pill, dark/light theme, and touch-optimized controls.
- [x] **GitHub Pages & Static Host Compatibility** — Fixed relative links, CORS headers, and client-side resilience.
